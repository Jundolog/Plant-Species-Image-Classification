# Plant-Species-Image-Classification
A. Project Overview

● Brief description of the project 

This project is a Seaweed Identification that uses Machine Learning to recognize different types of seaweed species. I trained a model using Teachable Machine with 20 different seaweed species found in coastal areas. For each seaweed type, I collected over 250 images showing different colors, shapes, and sizes. The model can now identify these seaweeds when shown a new picture. This could be useful for marine biology students, researchers, or anyone interested in learning about seaweeds along the shore.

● Purpose of the image classification model

The purpose of this image classification model is to automatically identify different types of seaweed species from photos.

Reflection Questions:
1. How did the number of images per class affect your model’s accuracy? More images = better accuracy. Species with 250+ images (like Sargassum) got 100% correct. Species with fewer images got only 70-80% accuracy. The model needs enough examples to learn properly.

2. Which plant species were most commonly misclassified and why? Brown seaweeds like Fucus and Kelp got mixed up most often because They look very similar (same color, shape, texture)Poor lighting in some photos made them hard to tell apart

3. How did changing the epochs, batch size, or learning rate affect the training results? Epochs: 50 worked best. 100 caused overfitting (model just memorized).
Batch size: 16 was good. 32 made training faster but less accurate.
Learning rate: Kept at 0.001 (default) because it worked fine

4. What challenges did you encounter during dataset collection and labeling? Hard to find 250+ good photos for every seaweed
Some seaweeds look almost identical easy to mislabel
Backgrounds (rocks, sand) sometimes confused the model
Different lighting made same seaweed look different

5. If you were to improve your model, what specific changes would you make and why?
My model works best when it has lots of good photos to learn from, and it struggles most with brown seaweeds that look alike.
